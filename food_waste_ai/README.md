# AI-Powered Food Waste Prediction & Redistribution System
Run order:
1. `pip install -r requirements.txt`
2. `python step1_generate_data.py`   -> dataset (swap with real data)
3. `python step2_eda_train.py`       -> EDA, features, models, evaluation
4. `python step3_redistribute.py`    -> optimized pickup plan
5. `streamlit run app.py`            -> dashboard
